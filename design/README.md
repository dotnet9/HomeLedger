# HomeLedger 离线交互原型

直接打开 [index.html](index.html)。该文件内嵌十个页面的 CSS、JavaScript、资源字典、配色令牌与图片；只复制这一个文件到空目录也可使用，无需服务器或联网。

| 页面 | 交互范围 |
| --- | --- |
| 登录 | 成员/管理员入口、密码修改、外观、关于 |
| 成员记账 | 快速新增、编辑、删除、备注搜索、分页与导航 |
| 存款利息 | 存入、选择、部分支取、利息结转、结算历史 |
| 成员报表 | 图表、汇总、导出入口 |
| 全家总览 | 成员比较、趋势、分类图表、明细导航 |
| 明细查询 | 筛选与 CSV 导出入口 |
| 成员管理 | 创建、启用/停用、重置密码与搜索 |
| 数据备份 | 备份入口与结果反馈 |
| 外观与语言 | 三种模式、八套配色、双语，跨页保留 |
| 关于与更新 | 检查、下载、校验、安装、取消、错误与缺少安装包场景 |

原型使用内存示例数据，重新载入会重置；安装与备份流程是演示状态，CSV 可下载。实际业务、认证、数据库备份与文件导出由桌面应用完成。

维护源文件保留在 mockups，原六页的卡片、表格、图表和弹窗均保留。新增四页补齐应用入口。CSS 共享 Studio 令牌，同时保留收入/支出的语义色与 Georgia 金额字体。不要直接编辑生成的 index.html。

```powershell
node scripts/build-prototype.cjs
node scripts/prototype-verification.cjs E:/github/temp/homeledger/prototype
```

验证使用 headless Playwright。将页面复制到空目录后检查十页、跨页状态、业务交互、更新场景与外部请求，再输出 1280×840 截图。对照结果和未消除的差异见 [FIDELITY.md](FIDELITY.md)。
