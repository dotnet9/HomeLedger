# design — UI 原型图

HomeLedger 家庭记账工具的 HTML 原型图，尺寸 1280×840（另含 24px 外边距投影），与桌面应用主窗口一致。用浏览器直接打开 `mockups/*.html` 即可预览。

## 视觉语言：「玉账」

- **圆角悬浮窗体**：16px 圆角 + 大投影，无边框感系统窗口；侧边栏为独立圆角浮层卡片。
- **配色**：玉绿（主色 `#147d64`）× 暖金（点缀 `#d9a441`）× 米白纸感底色（`#f7f5f0`）；收入竹绿、支出赭红，取"墨入玉版"的账本意象。
- **字体**：金额数字用衬线体（Georgia/宋体系），带手账账本的质感。
- **细节**：分割线用虚线（如账本行线）、统计标签前有金色小方点、主按钮玉绿渐变带投影、导航选中项为胶囊渐变。

## 界面清单

| 文件 | 视角 | 说明 |
|------|------|------|
| `mockups/login.html` | 公共 | 登录页：用户名 + 密码，首次登录强制改密提示 |
| `mockups/member-ledger.html` | 成员 | 记账主页：快速记账表单 + 筛选 + 近期记录列表 + 收支结余卡片 |
| `mockups/member-deposits.html` | 成员 | 存款利息页：存款链列表（本金/利率/起息日/应计利息）、存入/支取/结算、结算历史 |
| `mockups/member-report.html` | 成员 | 报表页：月度趋势柱状图、分类占比饼图、汇总表、四格式导出（CSV/PNG/PDF/DOCX） |
| `mockups/admin-overview.html` | 管理员 | 全家总览：成员对比、月度趋势、分类占比、明细查询标签页 |
| `mockups/admin-members.html` | 管理员 | 成员管理：账号列表、新建账号、停用/启用、重置密码 |

成员视角与管理员视角共用同一套窗口外壳（自定义标题栏 + 左侧导航），登录后按角色展示不同导航；"修改密码"与"结算确认"等以对话框形式呈现，原型中以弹层样式画在对应页面内。

共享样式见 `mockups/shared.css`（新配色已统一：玉绿/暖金/竹绿/赭红）。
