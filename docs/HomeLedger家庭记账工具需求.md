# HomeLedger 家庭记账工具 — 需求文档

> 版本：v0.1（2026-08-21）

## 1. 背景与目标

HomeLedger 是一款家庭自用的桌面记账应用，用于记录一家每个成员的收入与支出，并支持"儿女存钱在父母处、按约定利率计息"的家庭内部存款场景。

- 自用工具，单机运行，无需联网，无注册流程。
- 数据存储在本地文件数据库（SQLite），易于备份与迁移。
- 基于 .NET 10 + Avalonia 开发（参考项目骨架：Zitie）。

## 2. 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 管理员 | 只管理，不记账 | 创建/停用成员账号、重置密码、查看全家汇总与明细、导出全家报表（含存款利息） |
| 家庭成员 | 爸爸、妈妈、儿女等，每人一个账号 | 记录/查看/修改自己的收入与支出、管理自己的存款、查看自己的应计利息、导出自己的报表 |

规则：

- 每个成员登录后只能看到自己的账目，看不到他人的任何数据。
- 管理员不拥有记账数据，仅做管理与全局查看。
- 首次启动时初始化管理员账号（默认密码，首次登录强制修改）。
- 所有密码以 PBKDF2 哈希存储。

## 3. 功能需求

### 3.1 账号与登录

- FR-01 登录：用户名 + 密码登录，登录后进入各自视角的主界面。
- FR-02 管理员初始化：首次启动自动创建管理员账号；首次登录强制修改默认密码。
- FR-03 成员管理（管理员）：创建成员账号（用户名、显示名、初始密码）、停用/启用账号、重置密码。
- FR-04 修改密码：所有用户可自行修改密码。

### 3.2 记账

- FR-05 记一笔：类型（收入/支出）、金额、日期（默认今天）、分类、备注。
- FR-06 记录管理：查看、编辑、删除自己的记录（逻辑删除，保留痕迹）。
- FR-07 分类：内置常用收支分类（食品、交通、工资、利息等），用户可增删自定义分类（仅自己可见）。
- FR-08 筛选：按日期区间、类型、分类、关键词筛选自己的记录；显示收入合计、支出合计、结余。

### 3.3 家庭存款与利息

- FR-09 存款记录：成员可记录"存入父母处"的存款，每笔含金额、日期、年利率（默认 10%，每笔可单独修改）。
- FR-10 支取与追加：支取、追加均为新的记录，各笔本金按各自日期与利率独立起息。
- FR-11 利息计算：单利按日计息，利息 = 本金 × 年利率 × 天数 / 365，天数自存款日期（或最近结转日）起算至当前日期。
- FR-12 应计利息展示：随时显示每笔存款的当前应计利息、全部存款的本息合计。
- FR-13 利息结算（复利/结转本金）：成员（或管理员代操作）执行"结算"，将当前应计利息生成一笔新的"利息结转"存款记录，起息日重置为结算日，实现复利；结算前需确认。
- FR-14 结算历史：可查看历次结算记录（结算日、涉及笔数、利息总额）。

### 3.4 汇总与报表（管理员）

- FR-15 全家汇总：管理员可查看全部成员的收支汇总，支持按成员、按月份/年度、按分类筛选。
- FR-16 明细查看：管理员可查看每一笔明细（含存款与利息），可按成员筛选。
- FR-17 图形化展示：柱状图（月度收支趋势、成员对比）、饼图（分类占比）等。
- FR-18 报表导出：管理员可导出全家报表（默认包含存款利息部分），成员可导出自己的报表。格式支持：
  - CSV（纯数据）
  - PNG（图表快照）
  - PDF（图表 + 表格排版，QuestPDF）
  - Word .docx（图表图片 + 表格，OpenXML SDK）
- FR-19 报表内容：封面（时间范围、生成人）、收支汇总表、分类统计、月度趋势图、成员对比图（仅全家报表）、存款与利息明细表。

### 3.5 数据与备份

- FR-20 数据存储：SQLite 单文件数据库，存放在操作系统应用数据目录（如 `%LOCALAPPDATA%\HomeLedger\ledger.db`），不随安装目录、不入代码仓库。
- FR-21 数据备份：一键备份数据库文件到指定目录（复制带时间戳的副本）。

## 4. 非功能需求

- NFR-01 平台：Windows 优先（开发机为 Windows），Avalonia 跨平台能力保留 macOS/Linux 发布可能性。
- NFR-02 性能：万条级记录下列表加载、筛选、汇总 < 1 秒。
- NFR-03 安全：密码不出库（仅哈希）、成员数据隔离在查询层强制（按登录用户过滤）。
- NFR-04 界面：中文界面，Semi.Avalonia 主题，支持明暗主题切换。
- NFR-05 可靠性：所有金额使用 decimal，利息计算保留 2 位小数（四舍五入），避免浮点误差。

## 5. 边界与非目标

- 不做多设备同步、云存储、在线协作。
- 不做预算管理、记账提醒等扩展功能（可在后续版本考虑）。
- 不支持多账本/多家庭切换，单数据库即一个家庭。
